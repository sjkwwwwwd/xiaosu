## 这是什么

小黍是一个装在你电脑上的聊天助手。双击图标，弹出一个窗口，就能说话。

不用注册账号，不用填 API Key——它内置了一条免费通道，装完就能用。  
哪天想换更好的模型也行，左下角点一下，填自己的 Key，或者接本机的 Ollama。

和那些关掉就忘的聊天框不一样，它记得住。每句话都写进本地数据库，  
关机、重启、隔一周再打开，上次聊到哪儿它都清楚。

没有服务器，没有账号，没有云端同步。你聊的每一句都只留在自己硬盘上。

## 能做什么

|            |                                                             |
| ---------- | ----------------------------------------------------------- |
| **多轮记忆**   | 记得住上下文。告诉它"我叫阿豆"，隔几轮再问"我叫什么"，它答得出来                          |
| **对话不丢**   | 消息存在本地 `chat.db`，关掉重开都在                                     |
| **会话列表**   | 左下角「会话」，按最近活跃排序，随时切回几天前的对话                                  |
| **三种模型通道** | 内置免费 / 自己的 API（DeepSeek、硅基流动、OpenRouter、Groq、通义）/ 本地 Ollama |
| **流式输出**   | 逐字吐出来，不用干等一整段                                               |
| **独立窗口**   | 不是网页，没有地址栏和标签页，任务栏里就是一个普通应用                                 |

## 怎么运行

### 方式一：安装包（推荐）

双击 `Xiaoshu-Setup-1.0.0.exe`，一路下一步就装好了。会创建桌面快捷方式和开始菜单项，可以从「设置 → 应用」里正常卸载。

- 装到当前用户目录，**不需要管理员权限**，不会弹 UAC
- 不需要装 Python 或任何依赖
- 卸载时**不会删你的聊天记录**，重装后历史还在

### 方式二：免安装的绿色版

解压 `小黍-桌面版.zip`，双击里面的 `Xiaoshu.exe` 直接跑。适合放 U 盘随身带。

### 方式三：从源码运行

**Windows**：双击 `start-desktop.bat`

首次运行会自动建虚拟环境、装依赖（几分钟），之后秒开。

**其他系统**：目前只做了 Windows 的桌面外壳，Linux/macOS 可以手动跑：

```bash
python -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python desktop.py
```

> 需要 Python 3.10 或更高版本。Windows 还需要系统自带的 WebView2 运行时  
> ——Windows 11 默认就有，Windows 10 可以从微软官网下载安装。

### 数据存在哪

| 运行方式 | `chat.db` 位置                            |
| ---- | --------------------------------------- |
| 安装包  | 安装目录（`%LOCALAPPDATA%\Programs\Xiaoshu`） |
| 绿色版  | 解压后的文件夹里，和 exe 同级                       |
| 源码   | 项目目录                                    |

想备份或换电脑，拷走这一个文件就是全部记录。

## 三种模型，随便挑

窗口左下角那个头像按钮，点开就是模型设置。

### 内置免费（默认）

不用注册、不用填密钥，选中即可用。走第三方公共服务，模型 `gpt-oss-20b`。

代价是**约 4 次/分钟**的限速，而且它是别人提供的公共服务，不保证一直可用。适合试玩和演示。

### 自己的 API

填三样：接口地址、API Key、模型名。点「拉取」会自动取回该服务商真实可用的模型列表，不用手抄模型名。

内置了五个预设：

| 服务商        | 特点              |
| ---------- | --------------- |
| DeepSeek   | 国内直连，便宜         |
| 硅基流动       | 国内，有免费模型        |
| OpenRouter | 带 `:free` 后缀的免费 |
| Groq       | 速度快             |
| 通义千问       | 阿里云百炼，有免费额度     |

只要是 OpenAI 兼容接口，不在这五个里也能接。

### 本地 Ollama

装好 [Ollama](https://ollama.com/download) 后执行 `ollama pull qwen2.5:3b`，在设置里点「检测」，会列出本机已下载的模型。

完全免费、不限次数、不联网，全部跑在自己电脑上。

## 界面在哪操作

窗口只有三个区域：

- **顶栏** — 左边是小黍，右边「新会话」按钮
- **对话区** — AI 回复在左边带头像，你的消息在右边蓝色气泡；流式逐字输出
- **底部** — 输入框（`Enter` 发送，`Shift + Enter` 换行）和发送按钮

**左下角两个按钮**是关键：

- **会话** — 点开是历史对话列表，按最近活跃排序，点一条就切回去
- **头像** — 点开是模型设置，三条通道任选

## 技术栈

| 层    | 用了什么                                |
| ---- | ----------------------------------- |
| 桌面外壳 | pywebview + 系统自带 WebView2           |
| 界面   | 原生 HTML/CSS/JS，无框架无 CDN             |
| 本地服务 | FastAPI + SSE（只监听 127.0.0.1，外部访问不到） |
| 对话编排 | LangGraph（StateGraph + 检查点）         |
| 模型接入 | 自写的 provider 层，统一流式接口               |
| 存储   | SQLite（WAL 模式）                      |

对话图很简单，但骨架留好了扩展位：

```
START ──> trim_history ──> chatbot ──> END
            (修剪历史)      (调模型)
```

想加 RAG 就在中间插个检索节点，想加工具调用就在 `chatbot` 后面挂条件边。

## 常见问题

| 现象          | 原因                                  |
| ----------- | ----------------------------------- |
| 双击 exe 没反应  | 确认系统装了 WebView2 运行时；Windows 11 默认自带 |
| 提示「密钥无效」    | Key 填错或已失效，去服务商后台重新生成               |
| 提示「触发限流」    | 内置免费通道用太密，等几十秒或换通道                  |
| 提示「连不上接口地址」 | `base_url` 写错，注意要带 `/v1`            |
| 检测不到 Ollama | 没装或没启动，终端执行 `ollama serve`          |
| 回复到一半断了     | 关窗口会中断流，那一轮不入库，重发一次即可               |
| 想备份或迁移数据    | 拷走 exe 同目录的 `chat.db` 就是全部记录        |
